# CIT Computer Programming

A collection of Python exercises and assignments from the **Computer Programming** course.

This repository is organized by week and contains programs written while learning fundamental programming concepts using Python.

## 📚 Contents

| Week               | Topics                                                                                                  |
| ------------------ | ------------------------------------------------------------------------------------------------------- |
| [`week1`](./week1) | Python basics, `print()`, arithmetic, data types, strings, math functions, and simple calculations      |
| [`week2`](./week2) | Variables, operators, user input, arithmetic calculations, formatted output, and basic problem solving  |
| [`week3`](./week3) | Expressions, quadratic equations, BMI calculation, temperature conversion, and calculation exercises    |
| [`week4`](./week4) | Loops using `while` and `for`, `range()`, counters, and repetition exercises                            |
| [`week5`](./week5) | Loop-based problem solving, string checking, password validation, and binary-to-decimal conversion      |
| [`week6`](./week6) | Lists, indexing, list methods, iteration, counting values, reversing lists, and list-based calculations |
| [`week7`](./week7) | Two-dimensional lists, nested indexing, row and column processing, min/max values, and matrix transpose |

Some exercises also include example program output inside their corresponding `output/` directories.

## ▶️ Running

Python 3 is required.

Run an exercise with:

```bash
python3 week2/3-kncalc.py
```

or:

```bash
cd week4
python3 1.py
```
